# TRIX AI Assistant

This repository contains the scaffold for TRIX AI Assistant — an Expo + React Native + TypeScript project.

Quick start

1. Clone the repo
2. npm install
3. npm start

Branches
- feature/scaffold — initial scaffold
- main — stable releases

CI
- .github/workflows/ci.yml contains a basic CI pipeline (lint / type-check / test)

Notes
- No API keys or secrets are stored in the repository.
- Integrations are prepared as interfaces in src/services/ai.

UX / Design
- Hungarian localization ready in src/i18n
- Simple dashboard, chat, knowledge, projects and settings screens are included as a starting point.
